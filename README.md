# مجموعة بيانات التفسير المحرر (Tafsir Al-Muharrar Dataset)

مجموعة بيانات (Dataset) مفتوحة ومحققة برمجياً لموسوعة **التفسير المحرر** الصادرة عن **مؤسسة الدرر السنية**. يوفر المشروع المادة العلمية كاملة بصيغ مهيكلة (JSON) لتسهيل مهام البحث العلمي، ومعالجة اللغات الطبيعية (NLP)، وتطبيقات الذكاء الاصطناعي والتعليم الإسلامي، مع تزويدها بأدوات عرض وتحقق محلية.

> [!IMPORTANT]
> **تنبيه حقوقي**: المادة العلمية ومحتواها أصلها موسوعة التفسير المحرر الصادرة عن مؤسسة الدرر السنية. يتعين على مستخدم البيانات مراعاة شروط استخدام المصدر الأصلي وعزو المادة إلى أهلها عند أي استخدام خارجي.

> [!WARNING]
> **إخلاء مسؤولية وتنبيه هام حول حالة السكربتات وتوليد البيانات**:
> أُنشِئت مجموعة البيانات هذه لأغراض البحث العلمي والتجربة البرمجية. وننوه بأن البيانات المعتمدة حالياً في مجلد `json/` قد خضعت لـ **تعديلات وتصحيحات يدوية كثيرة ومباشرة** لتدارك الاختلالات الناجمة عن اضطراب بنية صفحات HTML في موقع المصدر ("الدرر السنية") وعدم اتساق معرفاتها.
> وبناءً عليه، فإن السكربتات البرمجية المرفقة في مجلد `scripts/` (مثل `json_generator.py`) وإن كانت قد استُخدِمَت في بداية المشروع لبناء الهيكل الأول للبيانات، **لم تعد صالحة لإعادة إنتاج البيانات أو التوليد الآلي من جديد**؛ إذ إن إعادة تشغيلها على ملفات HTML الخام تؤدي إلى محو التعديلات اليدوية الدقيقة التي أُدخلت على ملفات JSON.

## أصول البيانات المحلية (`tafseer html/`)

تمثل مجلدات `tafseer html/` المستودع الخام للبيانات المستخلصة؛ حيث تُفرد لكل سورة حافظة مستقلة تحتوي على:
* `المقدمة.html`: يحوي ديباجة السورة وفضائلها ومقاصدها.
* ملفات النطاقات (مثل `1-5.html` أو `12.html`): تحوي صفحات التفسير الخاصة بالآيات المعنية.

> [!NOTE]
> هذا المجلد متجاهل محلياً في مستودع Git لكبر حجمه. وقد استُخدِم محتواه في البداية مع السكربتات لاستخراج البيانات الأولية قبل إدخال التصحيحات اليدوية على ملفات JSON.

## حالة السكربتات وتوليد البيانات

> [!CAUTION]
> **تنبيه بخصوص عدم صلاحية إعادة التوليد البرمجي**:
> استُخدِمَت السكربتات المرفقة (`downloader.py`, `json_generator.py`) في مرحلة التأسيس الأولى لجلب الصفحات واستخلاص الهيكل المبدئي. بيد أنه نظراً لعدم اتساق بنية HTML في المصدر وحدوث اضطرابات متكررة في كلاسات المعرفات، فقد أُجريت **تعديلات يدوية واسعة النطاق** على ملفات الـ JSON مباشرة لإصلاح الأخطاء وتدقيق النصوص.
> وعليه، فإن السكربتات **غير صالحة لإعادة إنتاج البيانات**، ويُحذر من إعادة تشغيل سكربت التوليد الآلي على أصول HTML لأن ذلك سيمحو الإصلاحات اليدوية المحققة.

## مواصفات مخرجات JSON (`json/`)

يضم مجلد `json/` ملفات السور المستقلة (`1.json` إلى `114.json`). وتخضع البيانات لقواعد صارمة تمنع تسرب وسوم HTML وتفصل المتون عن الحواشي:
* **تجريد النصوص**: تُحفظ الحقول كنصوص ظاهرة خالية من وسوم التنسيق البرمجية.
* **إحالات الحواشي**: يُبقى في المتن رقم الحاشية المختصر كرمز ربط (مثال: `[15]`).
* **عزل المراجع**: تنقل النصوص الكاملة للحواشي إلى قائمة `references` الموزعة حسب الأقسام (التفسير، البلاغة، الإعراب، غريب الكلمات... إلخ).

لمزيد من التفاصيل حول هيكل الصفحات وقرارات المعالجة، يرجى مراجعة [docs/هيكل_الصفحات.md](file:///E:/GitHub/my%20workflows/json/%D8%A7%D9%84%D8%AA%D9%81%D8%B3%D9%8A%D8%B1%20%D8%A7%D9%84%D9%85%D8%AD%D8%B1%D8%B1/docs/%D9%87%D9%8A%D9%83%D9%84_%D8%A7%D9%84%D8%B5%D9%81%D8%AD%D8%A7%D8%AA.md) و [docs/ذاكرة_المشروع.md](file:///E:/GitHub/my%20workflows/json/%D8%A7%D9%84%D8%AA%D9%81%D8%B3%D9%8A%D8%B1%20%D8%A7%D9%84%D9%85%D8%AD%D8%B1%D8%B1/docs/%D8%B0%D8%A7%D9%83%D8%B1%D8%A9_%D8%A7%D9%84%D9%85%D8%B4%D8%B1%D9%88%D8%B9.md).

## الضوابط الهندسية ومعالجة البيانات (Technical Engineering Rules)

خضعت عملية استخلاص البيانات وتصفيتها لقواعد تقنية صارمة لضمان سلامة المتون ونقاء النصوص:

### 1. دقة تحديد نطاق الآيات
لضمان عدم تعطل الاستخلاص أو تسمية الملفات، يُعتمد تعبير نمطي (Regex) مرن يدعم كافة صياغات النطاقات في صفحات المصدر:
```regex
(?:الآيات|الآية|الآيتان|الآيتين)\s*[:]?\s*[\(]?\s*(\d+)\s*(?:[-–—]\s*(\d+))?\s*[\)]?
```

### 2. معالجة خطوط الآيات العثمانية
تستخدم صفحات المصدر حاوية `div#qpage` لعرض الآيات بخطوط عثمانية خاصة تظهر كرموز مبهمة عند الاستخلاص العادي. لمعالجة ذلك، يقوم السكربت بالبحث عن النص السليم المشكول للآيات من داخل أول وسم `span.aaya` في قسم التفسير ويستبدله بمحتوى حاوية الآيات كاملاً بصيغة اقتباس منسقة.

### 3. تنظيف وتجريد الـ HTML
لضمان خلو ملفات الـ JSON من أي وسوم أو أكواد زائدة، يتم القيام بما يلي:
* **حذف الأكواد البرمجية**: تفكيك وسوم `<style>` و `<script>` بالكامل من شجرة الـ HTML.
* **إزالة عناصر الواجهة**: حذف روابط التبويبات الداخلية والتعليقات المكتوبة بصيغة كلاسات التنقل الجانبية (`nav`, `collapse`, `menu`, `tabs`).
* **تصفية التعليقات والتكرار**: إزالة تعليقات المطورين البرمجية (`Comment` objects) ومعالجة الفراغات والأسطر الفارغة الزائدة.

## الأدوات البرمجية للحقيبة (Scripts & Tools)

تتوفر في مجلد `scripts/` حزمة من الأدوات البرمجية والسكربتات المساعدة لإدارة وتجهيز وعرض مجموعة البيانات:

### 1. أداة جلب وعرض التفسير (`scripts/get_tafsir.py`)
أداة سريعة ومرنة مبنية بواجهة سطر أوامر تفاعلية لعرض التفسير، وغريب الكلمات، والإعراب، والفوائد لسورة معينة أو نطاق محدد من الآيات.

* **الاستخدام الأساسي (عرض السورة كاملة بجميع حقولها وحواشيها)**:
  ```powershell
  python scripts/get_tafsir.py 112
  ```
* **عرض نطاق محدد من الآيات (الآيات من 2 إلى 3)**:
  ```powershell
  python scripts/get_tafsir.py 112 -f 2 -t 3
  ```
* **عرض أقسام معينة فقط دون حواشي (مثال: عرض الآيات والتفسير التفصيلي نظيفاً)**:
  ```powershell
  python scripts/get_tafsir.py 112 --verses --detail --no-ref
  ```
* **خيارات الأقسام المتاحة**:
  * `-i`, `--intro`: عرض المقدمة.
  * `-v`, `--verses`: عرض نص الآيات.
  * `-c`, `--vocab`: عرض غريب الكلمات.
  * `-m`, `--meaning`: عرض المعنى الإجمالي.
  * `-d`, `--detail`: عرض التفسير التفصيلي.
  * `-g`, `--grammar`: عرض الإعراب.
  * `-b`, `--balagha`: عرض البلاغة.
  * `-e`, `--edu`: عرض الفوائد التربوية.
  * `-s`, `--sci`: عرض الفوائد العلمية واللطائف.
  * `--no-ref`: إيقاف عرض الحواشي تماماً.

### 1.1. الواجهة الرسومية المحلية (`scripts/tafseer_gui.py`)
واجهة سطح مكتب مبنية على `wxPython` لتصفح السور والنطاقات وتصدير النص المعروض بصيغة Markdown.

* **أمر التشغيل**:
  ```powershell
  python scripts/tafseer_gui.py
  ```

### 2. سكربت التحميل التلقائي (`scripts/downloader.py`) [مرحلة أولية]
يتولى الاتصال برابط التفسير الرئيسي في موقع الدرر السنية وتتبع صفحات كل سورة بالتنقل الآلي وحفظها بصيغة HTML خام داخل مجلد `tafseer html/`.

### 3. سكربت توليد الـ JSON (`scripts/json_generator.py`) [مرحلة أولية]
قام باستخلاص وتوليد ملفات JSON المبدئية للسور من أصول HTML المحلية في بداية المشروع قبل إدخال التعديلات اليدوية.

### 4. سكربت التحقق والمطابقة (`scripts/validator.py`)
أداة تدقيق بنيوية تساهم في فحص مطابقة الحواشي والمراجع وتوزيعها وضمان سلامة المخطط لسورة محددة داخل مجلد `json/`.

* **أمر التشغيل (التحقق من سورة معينة)**:
  ```powershell
  python scripts/validator.py --surah 1
  ```

### 5. سكربت الاختبارات المؤتمتة (`scripts/run_tests.py`)
سكربت اختبار شامل يختبر سيناريوهات تشغيل أداة الجلب `get_tafsir.py` للتحقق من سلامة الأوامر وأكواد الخروج.

* **أمر التشغيل**:
  ```powershell
  python scripts/run_tests.py
  ```

### 6. مكتبة الدوال المشتركة (`scripts/helpers.py`)
ملف تجميعي برمجي يحتوي على خوارزميات تنظيف النصوص العربية، وتصفية وسوم HTML، وتصنيف مقالات التفسير والفوائد وتفكيك الحواشي والروابط.
